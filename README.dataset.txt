**Dataset Description**
This dataset was created by Yui Yokoyama, Tsutomu Matsui, and Takashi S.T. Tanaka for training instance segmentation models on cabbages in UAV imagery.

**Original Authors:**

* Yui Yokoyama
* Tsutomu Matsui
* Takashi S.T. Tanaka

**Paper:**

An instance segmentation dataset of cabbages over the whole growing season for UAV imagery (Data in Brief, 2024)

**Link:**
